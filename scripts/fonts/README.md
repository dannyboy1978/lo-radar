# Fonts for OG image generation

Bundled here so `scripts/gen-og.mjs` runs offline. Production runtime never
touches these — they're dev-only.

- **NotoSans-Regular.ttf / NotoSans-Bold.ttf** — sans-serif used for the
  "COMPARISON" eyebrow and the `loradar.com` URL footer. Open Font License
  (OFL), © Google.
- **DMSerifDisplay-Regular.ttf** — high-contrast display serif used for the
  large "LO Radar vs <Name>" headline and the gold "LO Radar" wordmark in
  the bottom-left. Open Font License (OFL), © Adobe.

Both fonts are SIL OFL 1.1 licensed and may be embedded and distributed.
